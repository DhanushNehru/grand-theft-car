# Contributing to Metro Drift

Thanks for wanting to make the city better.

## Ground rules

- Keep it dependency-free. The game is plain HTML/CSS/JS modules on purpose — no npm, no bundlers.
- Test in a real browser before opening a PR: serve the folder (`python3 -m http.server`) and actually play your change.
- Keep the code readable. Comments where the physics or AI does something non-obvious.

## How to contribute

1. Fork the repo and create a branch from `main`.
2. Make your change.
3. Open a pull request describing what changed and how you tested it (screenshots help a lot for visual changes).

## Good places to start

- More mission types (taxi fares, stunt jumps, timed races)
- Better traffic behaviour (indicators, avoiding the player, honking)
- Day/night cycle
- Sound effects and music
- Mobile control improvements

Check the issues labelled `good first issue` if you're new here.

## Reporting bugs

Open an issue with what you did, what you expected, and what happened instead. Include your browser and device.
